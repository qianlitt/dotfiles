# dotfiles
Archlinux's `.config`

## Neovim

我尚未进行任何个性化配置，而是直接使用了 LazyVim 的配置。若是有在新 PC 上配置 Neovim 的需求，那直接按 [LazyVim - Installation](https://www.lazyvim.org/installation) 中写的去克隆仓库即可。

> [!NOTE]
> 使用 LazyVim 需要一些依赖，可使用 `:checkhealth` 查看信息。[此处](https://www.lazyvim.org/#%EF%B8%8F-requirements) LazyVim 也详细列出了其所需的依赖。
